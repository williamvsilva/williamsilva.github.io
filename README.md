# William Vasconcelos — Portfólio

Portfólio profissional de William Vasconcelos, preparado para publicação no GitHub Pages.

## Publicação

Este projeto usa React + Vite. O workflow em `.github/workflows/deploy.yml` instala as dependências, gera a versão de produção e publica automaticamente no GitHub Pages a cada push na branch `main`.

Site esperado: https://williamsilva.github.io/
